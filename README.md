# Attendance Management System

A comprehensive university attendance management system featuring student registration, face upload, and administrative dashboards.

## Getting Started

### Prerequisites
- Node.js (v18+)
- Local storage for student records

### Running the Project
1. Navigate to the frontend directory:
   ```bash
   cd UNIVERSITY_ATTENDANCE/react-frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Deployment Settings
If you are deploying this to a platform like Render or Vercel, use these settings:
- **Root Directory**: `UNIVERSITY_ATTENDANCE/react-frontend`
- **Build Command**: `npm run build`
- **Publish Directory**: `dist`

## Updates
Use the included `update.cmd` script to quickly push your changes to GitHub.
